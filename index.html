w3: 什麼是 git, GitHub, gist 與 cmsimde? 如何使用這些工具？為什麼要使用這些工具？

git: 是一個安裝在你自己電腦上的軟體，用來記錄檔案的所有變更歷史。
透過終端機指令 (如 git init, git add, git commit, git push) 來操作。

GitHub: 是一個雲端平台，讓你存放 Git 的紀錄。在 GitHub 上建立一個 Repository (倉庫)，然後將本地端的 Git 紀錄上傳 (Push) 上去。

Gist: 是 GitHub 旗下的一個服務，專門處理「零碎」的內容，簡便版的 GitHub。

Brython 是什麼？
Brython: 是一個以 JavaScript 實作的 Python 3 實作版本。
就是在傳統的網頁開發中，瀏覽器只能讀懂 JavaScript (JS)。如果你想在網頁上寫邏輯，你必須學 JS。而 Brython 的出現，讓你可以直接在網頁的 HTML 檔案中撰寫 Python 程式碼，並在瀏覽器上直接執行，而不需要依賴後端伺服器。

如何在瀏覽器配置 Brython 環境？
1.引入 Brython 核心庫
2.初始化與撰寫

Brython 能做什麼？
Brython 幾乎可以做到 JavaScript 能做的所有事情，並且能發揮 Python 的語法優勢：
1.操作 DOM (網頁元素)： 像上面的範例一樣，你可以輕鬆抓取按鈕、改變文字內容或修改 CSS 樣式。
2.事件處理： 監聽點擊、滑動、鍵盤輸入等事件。
3.使用 Python 標準庫： 你可以使用 json、datetime、math 等 Python 內建函式庫來處理數據。
4.互動式繪圖： 配合 HTML5 的 Canvas 進行 2D/3D 繪圖（甚至是製作小遊戲）。
5.AJAX/HTTP 請求： 與後端伺服器通訊，抓取 API 資料。
6.教育用途： 對於已經熟悉 Python 但不想學習 JS 的學生或工程師來說，這是開發網頁前端最快速的路徑。
